# Agent reference (Horizon-derived)

These files were originally Cursor `.mdc` rules in `.cursor/rules/`. They
remain here as **read-only reference material for AI coding assistants** —
they document accessibility patterns, theme architecture conventions, and
representative examples from Shopify's Horizon theme.

They are **not loaded automatically** by Cursor (the `.cursor/` directory has
been removed) or by Copilot — Copilot's project instructions live in
[`AGENTS.md`](../AGENTS.md). Treat the files in this folder as a knowledge
base to consult on demand.
